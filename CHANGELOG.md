# Changelog

## 0.1.0

Initial prerelease:

- Strict versioned contracts and scalar constraints for CSV and JSONL.
- Disk-backed primary/composite uniqueness and cross-file references.
- Field comparisons, volume guards, and exact decimal sum reconciliation.
- Resource limits, bounded diagnostics and ordinary file-change detection.
- Redacted console, JSON, JUnit and offline HTML reports.
- CLI, public Python API and composite GitHub Action.
- Executable accepted/rejected commerce examples and cross-platform CI.

The contract is independent of Frictionless Table Schema and JSON Schema. This release reads local files and does not repair or import data.
